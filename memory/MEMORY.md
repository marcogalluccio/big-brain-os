     Each entry is a one-line pointer to a file in this folder.
     The file holds the full context. This index is the dashboard.

     Status codes:
     🔴 urgent / needs attention now
     🟠 stalled / waiting on someone or something
     🟡 active / in progress
     🟢 confirmed / on track
     🔵 done but loose ends still open
     ❌ closed or cancelled

     To add a project: create a file using project_template.md, then add a line here.
     To update status: edit the line here AND update the file.
     To close a project: change status to ❌ and move the file to memory/archive/ (soft-delete).

     The Advanced layer (salience / takes / soft-delete extras) is optional —
     see docs/ADVANCED.md. The Core schema works fine on its own. -->
