# The toolbelt

Big Brain is the context layer: who you are, what you work on, and what you are doing right now. The way you actually *do* the work (planning, building, debugging, research) comes from a small set of curated plugins and skills. This is the recommended toolbelt.

You do not need all of these on day one. Start with Superpowers, add the rest when a real task calls for it.

---

## Superpowers

The core of how you work. A discipline plugin for brainstorming, planning, test-driven development, and systematic debugging. The whole Big Brain setup is run through its `brainstorming` skill, so you learn the Superpowers way of working while you set up your brain.

**When to use it:** every time you start real creative or technical work. It is the default way of working, not an occasional tool.

**Install:** in Claude Code, run `/plugin`, then install Superpowers. Do this first, before anything else (see WELCOME.md, Step 0).

---

## impeccable

A design and polish skill for frontend interfaces.

**When to use it:** when you need to build or refine a professional site, landing page, dashboard, or product interface, and you want it to look genuinely good rather than generic.

**Install:** in Claude Code, run `/plugin` and install impeccable.

---

## deep-research

A research harness that fans out web searches, fetches sources, verifies claims adversarially, and synthesizes a cited report.

**When to use it:** when you need a verified, multi-source dossier for work: due diligence on a partner or client, a market scan, or any decision that should rest on more than a single search.

**Install:** in Claude Code, run `/plugin` and install deep-research.

---

## html-preview (already native)

A renderer that wraps any document you are building into a clean themed page and opens it in the browser.

**When to use it:** any time you want to *see* something rendered (a briefing, a comparison, a draft) instead of reading raw markdown. Just say "preview" or "show me".

**Install:** nothing to do. `html-preview` ships with this brain as a native skill.
