This domain covers all client-facing and project-based work: deliverables, project tracking, proposals, contracts, and client context. For background on active clients and goals, see `Context.md` in this folder.

## What This Domain Covers

- Active client engagements: briefs, deliverables, status tracking
- Project documentation: proposals, contracts, scopes of work
- Client context: background, goals, key contacts per engagement
- Post-project notes and follow-ups

Not covered here: internal operations (use a separate domain), or content produced for your own brand (use the `content` domain).

## Key Files

- `Context.md`: background, goals, active clients, reference links for this domain
- Add one subfolder per client or project as needed (e.g. `acme-corp/`, `project-x/`)

## When to Read This File

Read this file when:
- Working on any client deliverable or project task
- The user mentions a client name, engagement, or project deadline
- Drafting or reviewing proposals, contracts, or status updates

## Domain-Specific Rules

- Show any outreach draft to you before sending
- Keep client-specific raw materials (NDAs, confidential data) in a `raw/` subfolder that is gitignored
- Reference links and contacts go in `Context.md`, not scattered across random files
