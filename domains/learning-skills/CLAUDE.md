This domain covers professional learning: courses you are taking, skills you are building, certifications in progress, study notes, and resources you are working through. For background on your current learning goals and areas, see `Context.md` in this folder.

## What This Domain Covers

- Active courses or programs: status, materials, notes
- Skill-building initiatives: what you are practicing and why
- Certifications: requirements, deadlines, study plans
- Reading lists and study notes relevant to your work
- Post-course takeaways and how they apply to your practice

Not covered here: content you produce for others (use the `content` domain), or client deliverables that apply a skill you already have (use `clients-projects`).

## Key Files

- `Context.md`: background, current learning goals, resources, reference links
- Add one subfolder per course or skill track as needed (e.g. `course-name/`, `certification-x/`)

## When to Read This File

Read this file when:
- The user asks about a course, certification, or learning goal
- Drafting a study plan or summarizing course notes
- Deciding which skill to prioritize or how to apply new knowledge

## Domain-Specific Rules

- Keep raw course materials (videos, PDFs) outside the repo in a linked Drive folder
- Note the source and date whenever you capture a takeaway or quote
- Link every learning goal back to a professional outcome in `Context.md`
